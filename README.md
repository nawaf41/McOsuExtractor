## 🎵 What is McOsuExtractor?

Download osu! beatmaps from alternative sources without needing an official account or worrying about bans. McOsuExtractor automatically extracts and organizes your beatmaps and skins with zero hassle.

**Perfect for:**
- Players banned on the official osu! website
- Players without an osu! account
- Offline gaming enthusiasts

## ✨ Features

- 🤖 **Auto-Extract** - Automatically detect and extract beatmaps from downloaded files
- 📁 **Easy Setup** - Simple folder configuration with one click
- 👀 **File Watching** - Continuously monitors folders for new content
- ⏱️ **Background Mode** - Minimize to system tray and keep running

## 🚀 Quick Start

### Setup (2 minutes)

1. Download and run McOsuExtractor
2. Open **Settings** tab
3. Click "Select Folder" for Beatmaps (e.g., `C:\Users\YourName\Desktop\mcosu\songs`)
4. Click "Select Folder" for Skins (e.g., `C:\Users\YourName\Desktop\mcosu\skins`)
5. Check "Minimize to system tray" if you want background operation

### Start Extracting

1. Go to **Status** tab
2. Download beatmaps/skins from alternative sources (e.g., [beatconnect.io](https://beatconnect.io/) or similar sites)
3. Files automatically extract and are organized into your designated folders
4. Done! ✨
